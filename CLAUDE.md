# CLAUDE.md

This is the repository of smooth_sheets, a Flutter UI package that provides design-agnostic, highly customizable sheet components. Make sure to follow these guidelines when working on this project.

## Development

- The repository follows the standard structure of Flutter packages. It also provides executable sample apps in `example/lib/`.
- Make sure to use the Flutter SDK version specified in `.fvmrc`. Before getting started, verify this by running `fvm use` if FVM is available, or `flutter --version` otherwise.
- Feel free to add temporary files and modify existing files for debugging, as long as they are not committed to PRs.
- Before submitting a PR, make sure that all tests pass, the code is formatted, and there are no static analysis issues.
